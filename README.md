# 云曲线智能喷涂数据管理平台

基于 Node.js + Express + PostgreSQL 的多用户数据管理平台，支持 Excel 数据导入、权限管理、数据看板与可视化分析。

## 功能特性

### 🔐 用户与权限管理
- **管理员账号**：最高权限，可管理所有用户、上传数据、查看全部客户
- **子账号系统**：管理员可创建子账号并精细配置权限
  - 可查看的**客户范围**（指定客户或全部客户）
  - 可查看的**日期范围**
  - 可查看的**数据列**（指定列或全部列）
  - **导入权限**：是否允许上传 Excel
  - **导出权限**：是否允许导出数据
- JWT 令牌认证，登录速率限制防爆破

### 📤 Excel 数据导入
- 支持 `.xlsx` / `.xls` 格式，最大 50MB
- **导入模式：追加合并去重**
  - 同客户、同日期、同品牌车系车型、同部件、同起始时间的记录视为重复，自动更新
  - 新记录自动插入
- 自动识别 Excel 中的「汇总表」和各客户明细表
- 字段名智能匹配（支持多种别名）

### 📊 数据看板
- **客户总览**：所有客户的炉数、板件数量、时长、涂料用量等汇总统计
- **作业明细**：按日期聚合展示
  - 聚合行显示：日期、炉数（当天记录条数）、板件数量（当天总和）、其余数字列总和
  - 点击聚合行可展开查看当天全部明细记录
- **数字列排序**：客户总览和作业明细的数字列均支持点击表头升序/降序排序
- **筛选功能**：按客户名称、日期范围、炉数范围、板件数量范围筛选
- **列设置**：自定义显示哪些数据列和图表

### 📈 图表可视化
- 炉数 - 板件数量对比图
- 单炉平均时长图
- 客户板件数量排名图
- **部件数量统计图**（新增）
  - 自动拆分多部件字段（如「右前门_右后门」拆为「右前门」和「右后门」）
  - 支持逗号、换行、下划线等分隔符
  - 按出现次数统计，横向柱状图展示 Top 20

## 数据库表结构

### users（用户表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL | 主键 |
| username | VARCHAR(100) | 用户名（唯一） |
| password_hash | VARCHAR(255) | bcrypt 加密密码 |
| role | VARCHAR(20) | admin / sub |
| is_active | BOOLEAN | 是否启用 |
| created_at | TIMESTAMP | 创建时间 |

### user_permissions（权限表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL | 主键 |
| user_id | INTEGER | 关联用户 |
| customer_name | VARCHAR(200) | 可查看客户（空=全部） |
| date_start | DATE | 可查看起始日期（空=不限） |
| date_end | DATE | 可查看结束日期（空=不限） |
| allowed_columns | JSONB | 可查看数据列（空数组=全部） |
| can_import | BOOLEAN | 是否允许导入 |
| can_export | BOOLEAN | 是否允许导出 |

> 一个子账号可拥有多条权限规则，多条规则取**并集**。

### spray_records（作业记录表）
存储每条作业明细，含唯一约束用于去重（客户+日期+品牌+车系+车型+部件+起始时间）。

### customer_stats（客户汇总表）
存储 Excel「汇总表」中的额外统计字段（车辆数量、访问次数、各类下载次数）。

## 本地开发

### 1. 前置要求
- Node.js >= 18
- PostgreSQL 数据库（本地或 Neon/Supabase 免费实例）

### 2. 安装依赖
```bash
npm install
```

### 3. 配置环境变量
复制 `.env.example` 为 `.env` 并填写：
```bash
cp .env.example .env
```

```env
DATABASE_URL=postgresql://user:password@host:5432/dbname?sslmode=require
JWT_SECRET=你的随机长字符串
ADMIN_USERNAME=admin
ADMIN_PASSWORD=你的管理员密码（至少6位）
PORT=3000
```

### 4. 启动
```bash
npm start
```

访问：
- 登录页：http://localhost:3000/login
- 管理后台：http://localhost:3000/admin
- 数据看板：http://localhost:3000/dashboard

首次启动会自动创建数据库表和初始管理员账号。

## 部署到 Render

### 方式一：通过 render.yaml 一键部署（推荐）

1. 将本项目推送到 GitHub 仓库
2. 登录 Render 控制台，点击 **New** → **Blueprint**
3. 连接你的 GitHub 仓库，Render 会自动读取 `render.yaml`
4. 在环境变量配置页面填写：
   - `DATABASE_URL`：你的 PostgreSQL 连接串（推荐用 Neon 免费层）
   - `JWT_SECRET`：随机长字符串（可用 `openssl rand -hex 32` 生成）
   - `ADMIN_USERNAME`：管理员用户名（默认 admin）
   - `ADMIN_PASSWORD`：管理员密码（至少6位）
5. 点击 **Apply** 等待部署完成

### 方式二：手动创建 Web Service

1. Render → New → Web Service
2. 连接 GitHub 仓库
3. 配置：
   - **Runtime**：Node
   - **Build Command**：`npm install`
   - **Start Command**：`node --dns-result-order=ipv4first server.js`
4. 添加环境变量（同上）
5. 部署

### 数据库推荐

- **Neon** (https://neon.tech)：免费层 0.5GB 存储，自动扩展，适合中小数据量
- **Supabase** (https://supabase.com)：免费层 500MB，功能丰富

> 注意：Render 免费层 Web Service 会在 15 分钟无请求后休眠，首次访问需等待约 30 秒冷启动。如需始终在线可升级到付费层。

## 使用指南

### 管理员操作流程

1. **登录**：使用管理员账号登录，自动进入管理后台
2. **上传数据**：切换到「数据导入」标签，上传 Excel 文件
   - Excel 格式要求：第一个 sheet 名为「汇总表」，其余每个 sheet 名为客户名称
   - 明细表必须包含「时间」列，其余列自动识别
3. **创建子账号**：在「用户管理」点击「新建用户」，设置用户名密码
4. **配置权限**：点击用户行的「权限」按钮，添加权限规则：
   - 选择可查看的客户（留空=全部客户）
   - 设置日期范围（留空=不限）
   - 勾选可查看的数据列（留空=全部列）
   - 勾选是否允许导入/导出
5. 子账号登录后自动跳转到数据看板，只能看到权限范围内的数据

### Excel 文件格式要求

**汇总表（第一个 sheet，名称必须为「汇总表」）：**

| 设备 | 车辆数量 | 板件数量 | 起始时间 | 结束时间 | 访问次数 | 整车下载次数 | 整车部件下载次数 | 分离件部件下载次数 | 整车轨迹下载次数 | 分离件轨迹下载次数 |
|------|----------|----------|----------|----------|----------|--------------|------------------|--------------------|------------------|--------------------|
| 客户A | 5 | 6 | ... | ... | ... | ... | ... | ... | ... | ... |

**客户明细表（sheet 名为客户名称）：**

| 时间 | 设备 | 品牌 | 车系 | 车型 | 部件 | 板件数量 | 起始时间 | 结束时间 | 时长(min) | 清漆用量(g) | 色漆用量(g) | 珍珠用量(g) | 底漆用量() |
|------|------|------|------|------|------|----------|----------|----------|-----------|-------------|-------------|-------------|------------|
| 2026-08-21 | 客户A | 蔚来 | ES6 | 2019-2022 | 右前门_右后门 | 2 | ... | ... | 34.7 | 456 | 291 | 0 | 0 |

> 部件字段支持多部件组合，用下划线 `_`、逗号 `,` 或换行分隔，系统会自动拆分统计。

## 安全特性

- 密码使用 bcryptjs 加密存储（10 轮 salt）
- JWT 令牌认证，12 小时过期
- 登录速率限制：15 分钟内最多 10 次失败
- CORS 禁用（同源部署）
- 安全响应头：X-Content-Type-Options、X-Frame-Options、Referrer-Policy
- 错误信息脱敏（不向客户端泄露内部错误细节）
- 子账号数据隔离（API 层强制权限校验）

## 常见问题

**Q: 上传 Excel 后看板没有数据？**
A: 检查 Excel 第一个 sheet 是否名为「汇总表」，客户明细表是否包含「时间」列。刷新看板页面。

**Q: 子账号看不到某些客户？**
A: 管理员在「权限」设置中检查该子账号的客户范围配置。客户名留空表示可查看全部客户。

**Q: 部件统计图表数据为空？**
A: 检查明细表的「部件」列是否有数据。部件字段为空的记录不会被统计。

**Q: Render 部署后首次访问很慢？**
A: Render 免费层会休眠，首次访问需冷启动约 30 秒，属正常现象。

**Q: 如何修改管理员密码？**
A: 修改环境变量 `ADMIN_PASSWORD` 后重新部署。注意：这只会在管理员账号不存在时创建新账号，已存在的管理员密码不会被覆盖。如需修改已有管理员密码，可在管理后台创建一个新管理员账号，登录后删除旧账号。
